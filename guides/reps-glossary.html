FashionReps terms & reps slang (SuperBuy context)

A reps guide starts with shared vocabulary. This page explains common reps slang used around rep spreadsheets, w2c posts, and agent checkout—focused on what superbuyget actually helps with: browse, paste, QC on SuperBuy.

Core terms

W2C
Want to cop—a request for a buy link. See W2C meaning.
QC / qc pics
Quality control photos—warehouse shots after purchase. See QC photos for reps.
QC meaning (reps)
Verifying the physical item before international shipping—not approving a spreadsheet screenshot.
GL / RL
Green light to ship vs red light to reject/exchange—usually decided on SuperBuy QC photos.
GP
Often “group purchase” or context-specific shorthand in threads—always read the surrounding message; it is not a checkout button.
Rep finds / reps website
Curated link grids or browse sites that route you to marketplace permalinks—you still paste into an agent.
Rep spreadsheet / reps spreadsheet / replica spreadsheet
Any skim-friendly link table (Sheet, site, or Discord dump). Our spreadsheet lore page explains the culture; the home grid is a live shortlist.
Batch
Factory/run shorthand in sneaker threads (e.g. “LJR” gossip). Batch meaning (reps): chat labels, not certificates—confirm on QC photos, not row color in a sheet.
Trusted reps sellers
Community language for sellers with stable links—still reopen listings and read warehouse QC; no seller is “trusted forever.”

Other agent spreadsheets (not our focus)

Searchers also type kakobuy spreadsheet, cnfans spreadsheet, sugargoo spreadsheet, oopbuy spreadsheet, pandabuy spreadsheet, weidian spreadsheet, and similar. Those intents belong to other agents’ ecosystems. superbuyget.com is only a SuperBuy-oriented browse and paste companion—compare agents elsewhere; we do not publish coupon code lists or “is X legit” verdicts.

Promo codes, if any, appear inside SuperBuy’s official checkout during campaigns—not on third-party “{agent} coupon” landing pages.
